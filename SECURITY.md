# Security Policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

1. Open the [Security tab](https://github.com/AdityaK2128/nearloop/security) of this repository.
2. Choose **Report a vulnerability** and fill in the form.

Only the maintainers can see the report. Please include:

- The Nearloop version (Settings › About) and your macOS version.
- What an attacker can do, and the steps or a proof of concept that shows it.
- Anything you know about a fix.

You'll get a reply as soon as possible. The fix ships in a new release, and an advisory is published with it, crediting you unless you'd rather stay anonymous.

## Supported versions

Fixes go into the latest release only. The in-app updater (**Check for Updates…** in the Nearloop menu) installs it.

## Scope

This policy covers Nearloop itself: the app, its local server and its updater. Issues in the Kapitsa engine belong with the [Kapitsa project](https://github.com/nace-ai/kapitsa). If you aren't sure which one an issue belongs to, report it here.
